# Changelog

Todos los cambios relevantes del proyecto se documentan en este archivo.

## [1.0.0] - 2026-07-13

### Agregado

- Aplicacion React con Vite.
- Navegacion con React Router.
- Login cerrado con Supabase Auth.
- Restriccion de acceso a usuarios autorizados.
- Dashboard de arriendos activos por usuario.
- Historial de arriendos devueltos por usuario.
- Registro de arriendos con fotos de vehiculo y garantia.
- Soporte para multiples fotografias del vehiculo.
- Visualizacion ampliada de fotografias.
- Diferenciacion entre arriendo y porte.
- Edicion de arriendos activos.
- Marcado de arriendo como devuelto.
- Opcion para devolver un arriendo desde devuelto a activo.
- Eliminacion de arriendos con confirmacion.
- Agrupacion de arriendos por fecha.
- Diseno movil para uso principal desde telefono.
- Integracion con Supabase Database y Storage.
- Configuracion de despliegue en Vercel.

### Corregido

- Aislamiento de arriendos por cadenero.
- Eliminacion persistente de arriendos.
- Preservacion del usuario propietario al editar.
- Actualizacion de tarjetas difuminadas despues de eliminar registros.
- Ajustes visuales de tarjetas y estados en pantallas moviles.

### Estado

- MVP formalizado como version estable `1.0.0`.
